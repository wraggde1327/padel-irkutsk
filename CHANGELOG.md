# Changelog

## 0.2.0 — этап 1, 3 ноября 2026

- Каркас монорепо: `packages/shared`, `apps/api`, `apps/web`.
- Авторизация по Telegram initData (HMAC + срок) и JWT. Тесты подписи.
- Игрок и админ разведены: `/` только чтение, `/admin` — настройки, чемпионаты, площадки, партнёры, жеребьёвка.
- Владелец назначает админов (`StaffGrant`). Админ создаёт чемпионаты и правит взносы, название, сроки.
- Жеребьёвка: сгенерировать → проверить → сохранить черновик → опубликовать. Игроки видят только опубликованное.
- Состав дивизионов пропорциональный, добор с 3–4 мест (`fillFromPlaces`).
- `docker-compose.yml` для Postgres 16. Локально в этой среде Postgres установлен без Docker.
