# Changelog

## 0.5.0 — закреплённые пары и стартовый мастер

- Свободный режим: закреплённые пары (соперники по силе, 1-я vs 2-я на корте 1) или каждый круг заново 1+последний. Круговой график соперников — опция в настройках.
- «Сменить пары» на экране игр: рейтинг 1–8, рейтинг М+Ж, следующая М+Ж, случайно. Недоигранный круг: сыгранное остаётся.
- Стартовый мастер (формат, корты, М+Ж, закрепление пар, таблица, счёт, квалификация). После старта — строка-сводка и «Изменить».
- Счёт: матч = один сет по очкам, либо теннисные геймы с решающим. «Игр у пары подряд» убрано из очкового режима.
- Правка прошлого счёта предлагает пересобрать следующий круг, если в нём ещё нет очков.

## 0.4.0 — форматы мини-турнира и новые пары

- На вкладке «Игры» кнопка «Новые пары»: 1+последний по таблице, случайные любые, случайные М+Ж с минимумом повторов. Можно нажать в любой момент. Недоигранный круг: сыгранное остаётся в таблице, либо круг удаляется целиком.
- Формат турнира в настройках: свободный, американо, мексикано, эскалера, кинг. У каждого — однострочное описание. Старые сохранения подхватывают значения по умолчанию; `kingOfTheCourt` без формата становится «кинг».
- Американо: круговой график напарников (1-факторизация), личные очки, при числе не кратном 4 — очередь бай.
- Мексикано: после круга группы по Δ (затем победы), 1+4 vs 2+3 или 1+3 vs 2+4.
- Эскалера: три смены на корте, двое лучших вверх / двое худших вниз.
- Кинг: лучший из победителей вверх, слабый из проигравших вниз, на корте снова меняют пары.

## 0.3.0 — трекер мини-турнира

- Статическое приложение `tracker/` для учёта любительских кругов (падел/теннис) в браузере.
- Публикуется GitHub Pages по адресу `/tracker/` вместе с демо Mini App; исходный сайт не заменяется.
- Участники, счёт, пары, квалификация, таблица и сброс хранятся только в `localStorage`.

## 0.2.0 — этап 1, 3 ноября 2026

- Каркас монорепо: `packages/shared`, `apps/api`, `apps/web`.
- Авторизация по Telegram initData (HMAC + срок) и JWT. Тесты подписи.
- Игрок и админ разведены: `/` только чтение, `/admin` — настройки, чемпионаты, площадки, партнёры, жеребьёвка.
- Владелец назначает админов (`StaffGrant`). Админ создаёт чемпионаты и правит взносы, название, сроки.
- Жеребьёвка: сгенерировать → проверить → сохранить черновик → опубликовать. Игроки видят только опубликованное.
- Состав дивизионов пропорциональный, добор с 3–4 мест (`fillFromPlaces`).
- `docker-compose.yml` для Postgres 16. Локально в этой среде Postgres установлен без Docker.
