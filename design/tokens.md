# Токены макетов → CSS-переменные `apps/web`

Источник: макеты этапа 0. Имена совместимы с темой Telegram (`--tg-theme-*`). Боевое приложение читает `themeParams` в рантайме и подставляет те же слоты.

## Цвет

| Токен | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `--tg-theme-bg-color` | `#f2f3f5` | `#0e141a` | Фон экрана |
| `--tg-theme-secondary-bg-color` | `#e8eaed` | `#1a222b` | Вторичный фон, сегменты, чипы |
| `--tg-theme-section-bg-color` | `#ffffff` | `#18222d` | Карточка |
| `--tg-theme-text-color` | `#14171a` | `#f2f4f6` | Основной текст |
| `--tg-theme-hint-color` | `#7a828c` | `#8b96a3` | Подпись, вторичный текст |
| `--tg-theme-button-color` | `#1f8f5f` | `#2aa56e` | Акцент / главная кнопка |
| `--tg-theme-button-text-color` | `#ffffff` | `#ffffff` | Текст на акценте |
| `--tg-theme-section-separator-color` | `#e4e7eb` | `#2a3540` | Разделитель строк |
| `--tg-theme-link-color` | `#1f8f5f` | `#3dbe82` | Ссылка, «Назад» |
| `--status-ok` | `#1f8f5f` | `#3dbe82` | Победа / оплачено |
| `--status-ok-bg` | `#e6f4ed` | `#163528` | Фон статуса «ок» |

Один акцент — зелёный корта. Статус всегда дублируется текстом.

## Типографика

| Роль | Размер | Вес | Мин. кегль |
|---|---|---|---|
| Заголовок экрана | 24 px | 700 | — |
| Крупное число / пара | 20 px | 600 | — |
| Основной текст | 16 px | 400 | 16 px (поля ввода тоже) |
| Строка таблицы / слот сетки | 15 px | 400 | 14 px |
| Подпись, чип, таб | 14 px | 500 | 14 px |
| Колонка таблицы, «демо» | 13 px | 500 | 13 px только для служебного |

Семейство: `-apple-system, "Segoe UI", Roboto, sans-serif`. Межстрочный у крупного текста 1.25, у подписей ≥ 1.3.

## Отступы и радиусы

| Токен | Значение |
|---|---|
| Экран, горизонталь | 16 px |
| Зазор между блоками | 12 px |
| Внутренний отступ карточки | 16 px |
| Зазор между целями касания | ≥ 8 px |
| Радиус карточки | 16 px |
| Радиус кнопки | 14 px |
| Радиус чипа | 999 px |
| Радиус статуса | 12 px |

## Высоты целей касания

| Элемент | Высота × ширина |
|---|---|
| Главная кнопка | 52 px, на всю ширину |
| Второстепенная кнопка | 52 px |
| Нижний таб | 64 px, подпись обязательна |
| Строка таблицы / слот сетки | 48 px |
| Сегмент «Парой / Один», вкладка дивизиона | ≥ 44 px |
| Степпер «−» / «+» | 56 × 56 px |
| Кнопка «Назад» | ≥ 44 px |
| Строка «ключ / значение» в профиле | 44 px |

## Безопасные зоны

Контент начинается ниже статус-бара телефона (54 px в макете). Нижний таб + home indicator: `padding-bottom: 88 px + safe-area`. Главная кнопка регистрации липнет над табом и не пересекается с ним.
